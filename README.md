# ধর্মপুর টাইমস — নিউজ ওয়েবসাইট

সত্যের পক্ষে, জনতার পাশে। তোমার দেওয়া লোগো (`public/assets/logo.jpg`) আর ব্যানার (`public/assets/banner.jpg`) এই সাইটে বসানো আছে।

## এতে যা যা আছে

- পাবলিক নিউজ সাইট: হোম, ব্যানার, ব্রেকিং নিউজ টিকার, ক্যাটাগরি, সার্চ, খবরের বিস্তারিত পেজ
- অ্যাডমিন প্যানেল: নতুন পোস্ট, ছবি আপলোড, ক্যাটাগরি, ব্রেকিং, পাবলিশ/ড্রাফট, পোস্ট এডিট/ডিলিট, সাইট সেটিংস, পাসওয়ার্ড বদলানো, পোস্ট ব্যাকআপ ডাউনলোড
- নিরাপত্তা: পাবলিক সাইটে অ্যাডমিনের কোনো লিংক নেই। অ্যাডমিন শুধু সরাসরি `/admin` ঠিকানায় খোলে, আর পাসওয়ার্ড ছাড়া পোস্ট করা/ডিলিট করা যায় না। পাসওয়ার্ড শুধু scrypt হ্যাশ আকারে `data/data.json`-এ থাকে, খোলা লেখায় থাকে না। ভুল পাসওয়ার্ড ৫ বার দিলে ১০ মিনিটের জন্য লগইন বন্ধ থাকে।

## নিজের কম্পিউটারে চালানো (টেস্টের জন্য)

Node.js ১৮ বা তার বেশি লাগবে। কোনো আলাদা প্যাকেজ ইনস্টল লাগবে না।

```bash
node server.js
```

তারপর ব্রাউজারে যান: `http://localhost:3000`
অ্যাডমিন: `http://localhost:3000/admin` — প্রথমবার পাসওয়ার্ড সেট করুন (কমপক্ষে ৮ অক্ষর)।

## ফ্রিতে চালানো — সবচেয়ে সহজ উপায়

### উপায় ১: Render (ফ্রি, সুপারিশকৃত)

1. GitHub-এ একটা নতুন রিপোজিটরি খুলুন, এই ফোল্ডারের সব ফাইল আপলোড করুন।
2. [render.com](https://render.com)-এ ফ্রি অ্যাকাউন্ট খুলুন, **New → Web Service** বেছে GitHub রিপোজিটরি যুক্ত করুন।
3. Start Command: `node server.js`, Plan: **Free** বেছে Deploy করুন।
4. Render একটা ফ্রি লিংক দেবে, যেমন `https://dharmapur-times.onrender.com`। সেটাই আপনার পাবলিক সাইট।
5. সাইটের শেষে `/admin` লিখে প্রথমবার পাসওয়ার্ড সেট করুন।

মনে রাখবেন: Render-এর ফ্রি সার্ভিস কিছুক্ষণ ব্যবহার না হলে ঘুমিয়ে যায়, প্রথমবার খুলতে ৩০-৬০ সেকেন্ড লাগতে পারে।

## পোস্ট স্থায়ী রাখা — Supabase (সুপারিশকৃত)

ফাইলে পোস্ট রাখলে (আগের নিয়ম) ফ্রি সার্ভিসে রিডিপ্লয়/রিস্টার্ট হলে পোস্ট মুছে যায়। তাই এখন Supabase মোড আছে:

1. Supabase-এ ফ্রি প্রজেক্ট বানান, SQL Editor-এ `supabase-schema.sql` ফাইলের পুরো লেখা চালান (টেবিল তিনটা তৈরি হবে: `posts`, `site_settings`, `admin_account`)।
2. Render-এ সার্ভিসের Environment Variables-এ দুইটা ভ্যারিয়েবল বসান: `SUPABASE_URL` আর `SUPABASE_SERVICE_KEY`। **কী কখনো কোডে, GitHub-এ বা চ্যাটে দেবেন না — শুধু Render-এর env var-এ।**
3. রিডিপ্লয় করুন। এরপর পোস্ট, সেটিংস আর অ্যাডমিন পাসওয়ার্ড Supabase-এ থাকবে, রিডিপ্লয় করলেও মুছবে না।
4. দুইটা ভ্যারিয়েবলের একটাও না থাকলে সার্ভার আগের মতো `data/data.json` মোডে চলবে (লোকাল টেস্টের জন্য এটাই ব্যবহার করুন)।

**ছবির সতর্কতা:** Supabase মোডেও আপলোড করা ছবি (`public/uploads/`) Render ফ্রি সার্ভারের লোকাল ডিস্কে থাকে, তাই রিডিপ্লয় হলে ছবির ফাইল মুছে যেতে পারে (পোস্টের লেখা মুছবে না, শুধু আপলোড করা ছবিটা যাবে)। স্থায়ী ছবির জন্য সরাসরি ছবির লিংক (.jpg/.png/.webp) ব্যবহার করুন, আপলোড নয়।

### উপায় ২: Replit

1. [replit.com](https://replit.com)-এ ফ্রি অ্যাকাউন্ট খুলুন, এই ফোল্ডার আপলোড/ইমপোর্ট করুন।
2. Run বাটনে `node server.js` চালান, Replit যে পাবলিক লিংক দেবে সেটাই সাইট।
3. `/admin`-এ গিয়ে পাসওয়ার্ড সেট করুন।

## ডোমেইন লাগানো (পরে, ঐচ্ছিক)

নিজের ডোমেইন, যেমন `dharmapurtimes.com`, আলাদা করে কিনতে হয়। কেনার পর হোস্টিংয়ের সেটিংসে গিয়ে **Custom Domain**-এ ডোমেইনটি যুক্ত করুন, আর ডোমেইন কোম্পানির DNS-এ হোস্টিংয়ের দেওয়া রেকর্ড বসান। ডোমেইন কেনা/পেমেন্ট আপনার নিজের অ্যাকাউন্ট থেকে করতে হবে।

## পোস্ট করা / ডিলিট করা

1. সাইটের ঠিকানার শেষে `/admin` লিখুন, পাসওয়ার্ড দিয়ে লগইন করুন।
2. **নতুন পোস্ট** ফর্মে শিরোনাম, ক্যাটাগরি, সারসংক্ষেপ, বিস্তারিত লিখুন, ছবি দিন, **পোস্ট করুন** চাপুন।
3. পোস্ট ডিলিট করতে **সব পোস্ট** তালিকায় **ডিলিট** চাপুন, কনফার্ম করুন।
4. কাজ শেষে **লগআউট** চাপুন।

## ফাইলগুলো

- `server.js` — সার্ভার, অ্যাডমিন লগইন, পোস্ট API, নিরাপত্তা
- `public/` — পাবলিক সাইট, অ্যাডমিন পেজ, লোগো/ব্যানার, আপলোড করা ছবি
- `data/data.json` — পোস্ট আর সেটিংস (সার্ভার প্রথমবার চালালে তৈরি হয়)
- `render.yaml` — Render-এ ফ্রি ডিপ্লয়ের সেটিংস
